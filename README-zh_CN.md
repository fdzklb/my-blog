## NextJs + Shadcn UI + Tailwind + MDX(MD) + Postgresql + Prisma = blog

使用NextJS 15 App Router 版本，结合TypeScript、Shadcn UI、Tailwind、MDX(MD)、Postgresql、Prisma等技术构建的博客系统。

- NextJS 15 App Router + React 19 hooks，完美支持 SSR
- 支持`中英`多语言切换
- 使用mdx、md构建博客内容,并转成html格式
- 使用Prisma+Postgresql构建数据库
- 使用Vercel部署
- 样式适配手机、平板、PC等设备

## 🚀 快速开始

1. 克隆项目到本地 git clone https://github.com/fdzklb/my-blog.git
2. 安装依赖: `yarn`
3. 构建项目: `yarn dev` 启动本地开发
4. 构建项目: `yarn build + yarn start` 构建生产包+启动项目
