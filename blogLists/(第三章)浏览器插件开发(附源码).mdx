## CSDN无法复制的原理
1. 文字无法复制：复制文字弹出登录弹窗是因为劫持了copy事件并重写了copy事件。
![无法复制](/blogs/v3-3/img/text.png)

点击进入函数，我们可以看到被重写的函数逻辑，先检测权限，如果没有权限，则解绑**keydown**和**copy**事件，并弹出登录弹窗
![无法复制](/blogs/v3-3/img/func.png)

2. 代码无法选中：代码无法选中是因为给pre、code元素增加了user-select：none样式控制
![无法复制](/blogs/v3-3/img/css.png)

## 破解办法
利用静态注入的方式注入js脚本和css脚本，分别重写copy事件和重置user-select
```js
// scripts/content.js
// 恢复copy事件
document.addEventListener(
    "copy",
    (event) => {
      // 阻止默认行为和事件冒泡
      event.stopPropagation();

      // 获取选中的文本
      const selectedText = window.getSelection().toString();

      // 将选中文本写入剪贴板
      event.clipboardData.setData("text/plain", selectedText);
    },
    true
  );

```

```css
// scripts/styles.css
pre, code {
    user-select: text !important;
}
```

```json
// maingest.json
  "content_scripts": [
    {
      "matches": ["https://*.csdn.net/*"],
      "js": ["scripts/content.js"],
      "css": ["scripts/styles.css"],
      "run_at": "document_end", //当文档加载完成后执行脚本
      "all_frames": true //匹配所有frame
    }
  ],
```
